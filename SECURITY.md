# Security Policy

## Reporting a vulnerability
Email security@hipathai.me with details. We aim to respond within 72 hours and remediate critical issues within 30 days.

## Supported versions
Only the latest production deployment on `Main` is supported.

## Disclosure
Please do not publicly disclose until we have released a fix. Coordinated disclosure is appreciated.
