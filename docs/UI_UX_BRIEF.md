# HiPath AI — UI/UX Design Brief

## Principles
- Adaptive and mastery-driven
- Clear progression and gating
- Accessible and responsive
- Minimal cognitive load

## Key Surfaces
- Roadmap: phase cards, skill mastery, journey strip
- Lesson: structured blocks, quiz, practice, mastery score
- Tutor: multi-line composer, mode switch, threads
- Analytics: mastery, weak-skill recovery, benchmarks
- Settings: learning, accessibility, privacy, account

## Accessibility
- 44px touch targets
- Focus-visible outlines
- Reduced motion support
- ARIA live regions for async status
