# Search visibility (SEO) — what ships and what does not

**Last verified against production:** 2026-11-17, commits `5e987c6`, `59ae9d6`.

This page covers the crawlable layer only. Ranking is an outcome of content,
links, and time; the checklist below can be complete while the site still does
not rank for competitive queries. The honest split is at the bottom.

## What ships

| Layer | Where | Notes |
| --- | --- | --- |
| Per-page `<title>`, description, canonical | `src/lib/metadata.ts` → `pageMetadata()` | One helper for every marketing page. The root layout deliberately sets **no** canonical, otherwise pages without metadata claim the homepage as canonical. |
| Open Graph + Twitter card | same helper | The 1200×630 card is generated by `src/app/opengraph-image.tsx` (`/opengraph-image`) and referenced as `SOCIAL_IMAGE`. |
| `robots.txt` | `src/app/robots.ts` | Allows `/` and `/roadmaps/`; disallows `/api/`, `/dashboard`, `/roadmap` (the private app, not the public `/roadmaps`), `/start`, `/tutor`, `/code-e`, `/analytics`, `/settings`, `/onboarding`; declares the sitemap. |
| `sitemap.xml` | `src/app/sitemap.ts` | 26 URLs: 14 static pages, 5 guides, 7 public roadmaps. Dynamic: roadmaps come from `public_roadmaps`. |
| Apex → `www` redirect | Vercel domain config | `308` to `https://www.hipathai.me/`, so there is one canonical host. |
| Structured data | `src/app/page.tsx`, `src/app/about/page.tsx`, `src/app/roadmaps/[slug]/page.tsx`, `src/app/guides/[slug]/page.tsx`, `src/app/product-roadmap/page.tsx` | `SoftwareApplication` (home), `Organization` (about), `Course` + `FAQPage` + `BreadcrumbList` (roadmap), `Article` + `BreadcrumbList` (guide). |
| Bing verification | `public/BingSiteAuth.xml` | Served at `/BingSiteAuth.xml`, `200 application/xml`, token `77F3F09…709F`. |
| Google Search Console | owner's account | Verified outside the repo (no DNS TXT or meta tag in this codebase). Treat GSC as the source of truth for index status. |

`keywords` meta is intentionally absent: Google has ignored it since 2009 and
it is a spam signal for Bing.

## Bug fixed on 2026-11-17

Declaring `openGraph` in page metadata replaces the object Next inherits from
the root layout, including the image resolved from the file convention. Every
page that used `pageMetadata()` shipped **without** `og:image` and
`twitter:image` — `/guides`, `/roadmaps`, `/terms`, `/changelog`,
`/product-roadmap`, and the dynamic guide and roadmap pages. The dynamic pages
also carried no `twitter` block, so their `twitter:title` fell back to the home
page's title.

Fix (commit `5e987c6`): `SOCIAL_IMAGE` lives in `pageMetadata()`, the guide and
roadmap `generateMetadata()` call the same helper, and
`src/lib/metadata.test.ts` asserts the image is present. `/about` and
`/pricing` were the last two pages hand-rolling metadata without a twitter
block; they moved onto the helper in `59ae9d6`. Every public marketing page now
gets a page-specific `og:image`, `twitter:image`, alt text, and
`twitter:title`.

## Verify

```bash
# tags on a page that used to be broken
curl -s https://www.hipathai.me/guides/how-to-learn-python-from-scratch \
  | grep -oE '<meta (property|name)="(og|twitter):[^"]*"[^>]*>'

# the card itself
curl -s -o /dev/null -w '%{http_code} %{content_type} %{size_download}\n' \
  https://www.hipathai.me/opengraph-image

# crawl + index rules and the URL list
curl -s https://www.hipathai.me/robots.txt
curl -s https://www.hipathai.me/sitemap.xml | grep -c '<loc>'

# one canonical host
curl -sI https://hipathai.me/ | head -3
```

Bing: Webmaster Tools → add `https://www.hipathai.me` → XML file verification
(the file already serves) → submit `https://www.hipathai.me/sitemap.xml`.
"Import from Google Search Console" also works and copies the verified site and
sitemap in one step.

## What is not solved

- **Content depth.** 5 guides at 335–430 words and 7 public roadmap pages are
  enough to be indexed, not enough to compete for "learn Python" or
  "machine learning roadmap". Long-tail pages need 1,200+ words, code, a table
  of contents, and links to the matching roadmap and sign-up.
- **Authority.** Rankings for head terms are mostly backlinks and domain
  history. Neither exists yet.
- **Brand-first titles.** The home title is "HiPath AI — Your Personal AI
  Learning Navigator", which matches no search query. Roadmap and guide titles
  are query-shaped; the home page is the exception.
- **FAQ rich results.** The roadmap pages emit `FAQPage`, but Google now shows
  FAQ results only for authoritative government and health sites. It is
  semantic polish, not a visibility lever.
- **Index status cannot be measured from CI.** Google needs JavaScript to
  render `site:` queries and Bing's RSS endpoint returns zero items, so GSC and
  Bing Webmaster Tools are the only reliable sources.

## Sequence if search traffic matters

1. Pick 10 long-tail queries already covered by a public roadmap.
2. Expand the 5 guides to 1,200–1,800 words and publish 5 more on the same
   pattern, each linking to its roadmap.
3. Add internal-link blocks between guides, roadmaps, and sign-up.
4. Earn links: GitHub README, dev.to, Reddit/HN answers, Product Hunt,
   open-source mentions.
5. Watch GSC: indexed pages, impressions, non-brand clicks, average position
   for the 10 targets. A 90-day target of first page for 3 long-tail queries is
   realistic; top-3 for head terms is not.
